# Dodger Game

A 2D arcade dodge game built with Python and Pygame. Control a blue player square and dodge falling red blocks.

---

## Features

- **Smooth 60 FPS gameplay** using Pygame's clock timing.
- **Bounding box collision detection** (AABB) between player and obstacles.
- **Screen boundaries** preventing the player from wandering off-screen.
- **Dynamic obstacle respawning** with randomized positions.

---

## Controls

| Key | Action |
| :--- | :--- |
| **Arrow Up** | Move up |
| **Arrow Down** | Move down |
| **Arrow Left** | Move left |
| **Arrow Right** | Move right |
| **Close Window** | Exit game |
